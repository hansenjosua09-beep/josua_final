Tentang Proyek
JH
Latar Belakang Jurusan DKV & Praktik Kerja Lapangan

Banyak yang mungkin penasaran, kenapa saya memilih mengangkat nama dan tema Sigma Digital Printing? 🤔

Sebelumnya, saya adalah siswa SMK dengan latar belakang jurusan Desain Komunikasi Visual (DKV). Saat masih duduk di bangku SMK, kami diwajibkan menjalani program Praktik Kerja Lapangan (PKL) untuk mencari dan menimba pengalaman nyata di dunia industri. Pada momen berharga itulah, saya sempat ditugaskan dan berkesempatan menimba ilmu langsung di perusahaan Sigma Digital Printing yang berlokasi di Paal 2, Manado.

Pengalaman Nyata
JH
Alasan Memilih Tema Sigma Digital Printing

Di Sigma Digital Printing, mata saya benar-benar terbuka lebar melihat bagaimana industri kreatif percetakan bekerja: dari proses cetak baliho raksasa, presisi digital offset lembaran A3+, stiker kemasan produk, hingga berbagai media promosi indoor dan outdoor.

Saya membuat website ini karena menurut saya sangat keren dan bermakna jika saya membuat website dari tempat yang sudah berjasa membantu saya untuk mengenal dan merasakan langsung dunia kerja untuk pertama kalinya! 🚀

Inspirasi & Makna
JH
Dedikasi & Terima Kasih untuk Sir Wilsen

Melalui website ini, saya menggabungkan fondasi estetika visual yang saya pelajari dari SMK DKV dengan keterampilan pemrograman web modern (HTML5, Bootstrap 5, styling CSS Merah-Hitam-Putih yang elegan, dan fitur interaktif JavaScript seperti kalkulator cetak dan pencarian produk).
